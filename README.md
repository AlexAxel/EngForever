# Eng Forever

Адаптивный сайт для тренировки перевода по собственным записям. 40 пар фраз, один тип карточек «Перевод». Без сервера, сборки и сторонних библиотек.

## Публикация

Откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите **main** и **/(root)** и нажмите **Save**. После успешной публикации адрес должен быть https://alexaxel.github.io/EngForever/ (проверьте фактический адрес на странице Pages).

**Приватный репозиторий:** возможность публикации Pages из приватного репозитория зависит от тарифа GitHub. Если опция недоступна, не изменяйте приватность без решения владельца. Даже Pages из приватного репозитория является публичным сайтом, тексты фраз посетителям доступны.

## Использование

Начните тренировку. Перевод скрыт: потяните за язычок шторки вниз, проверьте себя и затем свайпните карточку влево (ошибка) либо вправо (верно). Есть и дублирующие кнопки. При ошибке карточка перемещается в конец очереди текущего круга до правильного ответа. После освоения активной колоды автоматически начинается круг сложных фраз, если они остались. Порядок первоначального прохода случайный, без повторений.

В настройках можно выбрать язык лицевой стороны и включать или отключать отдельные ID. Прогресс, общая статистика по двум направлениям перевода и динамическая сложность сохраняются в localStorage **только текущего браузера**. Очистка данных браузера удалит прогресс; синхронизации нет. Сложность повышается от ошибки и уменьшается после верных ответов.

## Добавление фраз

Файл `data/phrases.json` — массив объектов вида:

```json
{"id": 41, "ru": "Русский текст.", "eng": "English text."}
```

Используйте уникальный ID непосредственно из тетради, не перенумеровывайте существующие карточки: к ID привязана статистика. После коммита в main GitHub Pages обновит данные на сайте при следующей публикации. Новые ID активны по умолчанию.

## Архитектура

`index.html` — интерфейс; `styles.css` — адаптивный дизайн и автоматическая светлая/тёмная тема; `app.js` — колода, жесты, статистика; `data/phrases.json` — данные. Для локального запуска используйте HTTP-сервер (например, `python -m http.server 8000`), а не открывайте HTML через file://.

В версии 1 тип «Перевод» имеет 100% вероятность. Режимы распределения типов «автоматически / вручную» сохраняются, но различий между ними пока нет: второго типа ещё не существует. Для следующих типов потребуется расширить типизацию карточек и UI назначения вероятностей. Проверка ответа самостоятельная: голосовое распознавание не реализовано.
